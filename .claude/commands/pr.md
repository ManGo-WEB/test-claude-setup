Подготовь Pull Request:

1. Покажи `git diff main...HEAD` (или master, если main нет)
2. Сформулируй заголовок в Conventional Commits
   (feat:, fix:, refactor:, docs:, chore:, test:)
3. Опиши:
   - **Что изменилось** (короткий список)
   - **Зачем** (мотивация изменений)
   - **Как проверить** (шаги для ревьюера)
   - **Риски** (что может сломаться)
4. Перечисли затронутые тесты и есть ли новые
5. НЕ делай git push автоматически — только покажи готовый текст и команду
